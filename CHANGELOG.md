# Changelog

## 0.1.0

First release.

- `scan` measures the images of live pages in headless Chromium, per view and per viewport. It reports exact and
  est. byte savings, sharpness growth, and a SSIMULACRA2 quality check.
- The `skills/imgtune` agent skill and the composite GitHub Action in `action.yml` ship with the package.
- Requires Node.js 20.9 or later and Chromium for Playwright.
