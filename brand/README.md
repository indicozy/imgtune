# Brand

The imgtune logo: a cut-paper photo card with a sun, hills and a slider.

- `logo/out/`: final files. `mark` and `lockup` (mark plus wordmark), each with a `-dark` version, and `favicon.svg`. Each has an SVG and a PNG.
- `logo/d.py`: builds `out/`. Run `python3 logo/d.py`. It needs `fonttools`.
- `logo/gen.py`: the shape helpers and the first four concepts (`concept-*.svg`).
- `fonts/`: Fraunces, the wordmark font, under the SIL Open Font License (`OFL.txt`). The SVGs use outlines, so they do not need the font.

Colours: paper `#E6DFD0`, cream `#F1EDE4`, clay `#C9643F`, ink `#1F1D1A`.
